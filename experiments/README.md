# Экспериментальные сценарии

Каталог содержит только корневые сценарии, необходимые для воспроизведения
экспериментальной части ВКР. Генераторы рисунков рукописи, внутренние
вспомогательные скрипты и результаты запусков в snapshot не включены.

| Скрипт | Назначение |
|---|---|
| `exp1_dynamic_regime.py` | Поиск рабочего динамического режима в последовательности NeuroGym-задач |
| `exp2_task_robustness.py` | Проверка устойчивости выводов на разных наборах задач |
| `exp3_connectome_topology.py` | Сравнение топологии коннектома и нуль-моделей |
| `exp3v2_biological_node_routing.py` | Сравнение биологически обоснованных маршрутов входа и выхода |
| `exp3v3_connectome_vs_synthetic_routing.py` | Сравнение эмпирического коннектома и синтетических резервуаров |
| `exp4_readouts_forgetting.py` | Сравнение readout-моделей при динамической интерференции |
| `exp5_biological_activations.py` | Последовательные сценарии с биологическими функциями активации |
| `exp5v2_activation_task_sweep.py` | Автономная ёмкость функций активации на отдельных задачах |
| `exp6_optuna_optimization.py` | Поиск конфигураций с Optuna |
| `exp6_confirmatory_analysis.py` | Агрегация подтверждающей проверки найденных конфигураций |
| `exp6_diagnostic_analysis.py` | Диагностический анализ результатов Optuna |
| `exp6_search_strategy_visualization.py` | Сравнение стратегий grid search и Optuna |
| `exp7_alternative_reservoirs.py` | Сравнение альтернативных архитектур резервуара |
| `exp7_biological_high_rho_routes.py` | Проверка биологических маршрутов при высоком спектральном радиусе |

## Соглашения

- Базовое случайное зерно: `42`.
- Новые результаты записываются в локальный каталог `results/`.
- Основной набор данных находится в `data/human/`.
- Код и CSV сохраняют исторический ключ `forgetting` для воспроизводимости.
  В интерпретации ВКР это относительное падение точности при динамической
  интерференции, а не классическое катастрофическое забывание общего readout.
- Аналитические скрипты Exp6 требуют ранее полученных каталогов результатов и
  не предназначены для запуска как самостоятельный smoke-тест.

## Запуск

Перед запуском установите окружение и данные из корневого README. Аргументы
конкретного сценария можно посмотреть через `--help`, если скрипт имеет CLI:

```bash
uv run python experiments/exp3v2_biological_node_routing.py --help
```

Не запускайте `exp6_confirmatory_analysis.py` и `exp6_diagnostic_analysis.py`
для просмотра справки: это анализаторы готовых результатов без отдельного
CLI-режима.
