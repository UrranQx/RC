# Коннектом-информированные резервуарные вычисления

Воспроизводимый публичный snapshot экспериментов выпускной квалификационной
работы по исследованию резервуарных вычислений на структурных коннектомах
человека. Репозиторий содержит экспериментальные сценарии, локальную версию
`conn2res`, тесты, получение открытых данных с Zenodo и зафиксированное
окружение `uv`.

## Основные выводы

- Для последовательного решения разнотипных задач устойчивой базовой
  конфигурацией является ESN с `tanh` и спектральным радиусом около `0.8`.
- Биологически обоснованный маршрут `subctx_ctx` даёт низкое относительное
  падение точности и используется как основной маршрут; другие маршруты
  сохраняются для сравнительного анализа.
- Структура эмпирического коннектома влияет на качество и интерференцию:
  результаты сопоставляются с топологическими нуль-моделями и синтетическими
  резервуарами.
- Линейный `RidgeClassifier(alpha=0.0, fit_intercept=False)` остаётся
  практическим базовым readout. Более сложные readout-модели не дали
  устойчивого преимущества, достаточного для смены базовой конфигурации.
- Биологические функции активации могут превосходить `tanh` в отдельных
  автономных задачах, но не устраняют последовательную интерференцию.
- Optuna используется для поиска кандидатов, после чего конфигурации требуют
  отдельной подтверждающей проверки на субъектах и консенсусных коннектомах.

## Быстрый старт

Требуются Python 3.13 и установленный
[`uv`](https://docs.astral.sh/uv/).

```bash
git clone https://github.com/UrranQx/RC.git
cd RC
uv sync --locked --extra dev
uv run python scripts/download_data.py
uv run python scripts/download_data.py --check
```

Загрузка создаёт проверенный набор массивов в `data/human/`. Архив и формы
массивов проверяются до установки данных. Существующий валидный набор не
перезаписывается; для замены неполного или повреждённого набора используйте
`--force`.

## Пробный запуск

Короткий запуск проверяет загрузку коннектома и основной вычислительный
маршрут без MLflow и построения графиков:

```bash
uv run python experiments/exp3v2_biological_node_routing.py \
  --stage smoke \
  --disable-mlflow \
  --skip-plots \
  --no-progress
```

Полное описание сценариев приведено в
[`experiments/README.md`](experiments/README.md).

## Данные

Основной набор загружается из
[Zenodo record 10205004](https://zenodo.org/records/10205004) скриптом
`scripts/download_data.py`. Он содержит групповой массив из 70 субъектов,
консенсусные матрицы и метаданные узлов Lausanne 1015.

Бинарные данные не хранятся в Git. Для нестандартного расположения данных
передайте `--output-dir` downloader-скрипту и задайте переменную окружения
`CONN2RES_DATA_DIR`. Переменная `CONN2RES_ROOT` по-прежнему задаёт корень
проекта, если отдельный путь данных не указан.

Дополнительный источник индивидуальных многомасштабных коннектомов:
[Zenodo record 2872624](https://zenodo.org/records/2872624). Он не требуется
для стандартного воспроизведения экспериментов этого snapshot.

Подробности и ожидаемые формы массивов приведены в
[`data/README.md`](data/README.md).

## Результаты и MLflow

Экспериментальные скрипты создают локальные каталоги `results/`, `mlruns/` и
SQLite-базы при необходимости. Эти артефакты намеренно не включены в
публичный snapshot: репозиторий содержит код воспроизведения и основные
выводы, но не внутренние отчёты и сырые результаты.

Для локального просмотра MLflow:

```bash
uv run mlflow ui --backend-store-uri sqlite:///mlflow.db --port 5000
```

## Проверка

Профиль локальной проверки соответствует CI:

```bash
uv run ruff format --check conn2res experiments scripts tests
uv run ruff check conn2res experiments scripts tests
uv run pytest conn2res/tests tests \
  --deselect=conn2res/tests/test_connectivity.py::TestConn::test_randomize \
  --deselect=conn2res/tests/test_connectivity.py::TestConn::test_get_nodes
```

Два исключённых теста являются известными upstream-несоответствиями текущей
версии `conn2res`. Тесты legacy Exp4.2 автоматически пропускаются, поскольку
соответствующий внутренний сценарий не входит в публичный snapshot. Остальные
тесты выполняются в CI с `MPLBACKEND=Agg`.

## Структура

| Путь | Назначение |
|---|---|
| `conn2res/` | Локальная версия библиотеки резервуарных вычислений и её тесты |
| `experiments/` | Четырнадцать корневых сценариев экспериментов и анализов |
| `scripts/download_data.py` | Загрузка и строгая проверка набора данных |
| `data/` | Пустая структура для локальных данных и кэшей |
| `tests/` | Тесты публичной инфраструктуры snapshot |
| `.github/workflows/ci.yml` | Проверка форматирования, импортов и тестов |
